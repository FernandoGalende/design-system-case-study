Alert and Card components

Live examples of ds-alert and ds-card, with usage snippets. Both components are built only from the shared design tokens, so the brand switcher at the top right restyles every example for Luma or Nova without changing a component. The Alert follows the design specification (opens in a new tab); the Card has no specification and reuses the Alert's visual language.

COMPONENT

Alert

Alerts that are already on the page when it loads use live="off", so screen readers don't announce them on load. Alerts that appear later keep the default: errors are announced assertively (role="alert"), everything else politely (role="status").

COMPONENT

Card

The Card has no specification: it reuses the Alert's surface, radius, spacing and type scale, so both read as one system in either brand. Header, image and footer are optional slots; content outside them is the body.
