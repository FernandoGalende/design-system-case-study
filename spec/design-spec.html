Behavior notes

Intentionally open:
Choose and justify the public component API, content-projection strategy, action API, icon strategy, event naming, and exact assistive-technology semantics.
Expected constraints:
One implementation must serve both brands. The component should work at narrow widths and with wrapped content. Interactive elements must be keyboard usable and have usable focus treatment.
